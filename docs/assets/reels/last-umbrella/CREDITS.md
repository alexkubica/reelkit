# The Last Umbrella — credits

Original fiction written for the ReelKit library. Characters, city, events, and impossible weather are invented.

- Story and editorial direction: original ReelKit microfiction.
- Illustrations: six original AI-generated images made with OpenAI image generation; no external photographs or stock assets. Full prompts are retained in the local working project.
- Narration: synthetic British English voice `en-GB-RyanNeural`, generated using the optional `edge-tts` service. Caption highlights use the service’s actual word-boundary events, merged only where the provider split a hyphenated word.
- Production: the `create-reel` skill, ReelKit portable renderer, and FFmpeg audio mastering.
- Typography: Noto Sans, distributed under the SIL Open Font License; see the repository font attribution.
- Music / sound effects: none. English captions are burned into the image; no CC track.
